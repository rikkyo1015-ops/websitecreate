# 椿参道クリニック — サイト制作サンプル

新規開院クリニック向けの日本語サイトです。Vite と HTML / CSS / JavaScript を使用しています。

公開サイト: https://rikkyo1015-ops.github.io/websitecreate/

制作経緯・確定済み情報・未完了の写真差し替え・次回の作業手順は [制作引き継ぎメモ](docs/PROJECT_HANDOFF.md) に保存しています。作業を再開する際は最初に確認してください。

参考サイト（https://www.sugamo-uro.com/）の配色・構成を確認し、紺・白・赤のデザイン、大きな写真と曲線、アイコン付きナビゲーション、症状から探す案内へ改修しました。文章・ロゴ・写真は本サイト用の内容を使用しています。

## 開発

Node.js 20.19+ または 22.12+ が必要です（この環境では Node.js 24）。

```sh
cd /workspace/websitecreate
npm ci --cache /tmp/websitecreate-npm-cache
npm run dev -- --port 5173
```

## 本番用ビルド

```sh
npm run build
npm run preview -- --port 4173
```

生成された `dist/` を静的サイト対応のホスティングへ配置できます。ビルドや開発サーバーの起動だけでは、一般公開されません。

## GitHub Pages

`.github/workflows/pages.yml` に公開用ワークフローを用意しています。リポジトリの Settings → Pages の Source を GitHub Actions に設定すると、main への push またはワークフローの手動実行で公開します。

GitHub Pages用ビルドは `npm run build -- --base=/websitecreate/` です。画像切り替え・画像拡大も含め、サブディレクトリからの配信に対応しています。

## 掲載内容

- 診療案内（詳細ダイアログ）
- 当院の特徴
- 設備・院内紹介（画像拡大）
- 院長のご挨拶・経歴
- 診療時間・アクセス
- 月を切り替えられる休診カレンダー
- 予約画面の操作サンプル
- お知らせ・よくあるご質問
- スマートフォン用メニュー・固定予約ボタン
- メイン画像の切り替え、症状・健康管理から探すタブ（キーボード操作対応）
- PC表示の固定予約・初診・アクセスボタン

## 実際の医院情報への差し替え

医院名「椿参道クリニック」・院長名「阿部陽介」は指定の情報です。駅名・住所・診療内容・診療時間・経歴・お知らせは仮情報です。`index.html` と `src/main.js` にある該当箇所を差し替えてください。実際の所在地と連絡先はまだ掲載していません。

画像は本サイト向けに生成した架空のクリニック・医師のイメージです。

- `public/images/clinic-hero.png`: 待合室・受付の写真イメージ
- `public/images/clinic-doctor-hero.png`: 医師と明るいクリニックのメイン画像
- `public/images/clinic-atlas.png`: 医師、診察室、検査設備、外観の4分割画像。CSSで各領域を表示しています。

カレンダーは日本時間の現在月を初期表示し、水曜・日曜の休診、土曜の午前診療を示します。**祝日・臨時休診はまだ反映していません。** 実際の休診スケジュールに合わせて設定が必要です。

予約画面は入力内容をその場で確認するデモです。予約の送信・確定、個人情報の収集・保存は行いません。運用前に医院の予約システムへ接続し、プライバシーポリシーも実際の運用に合わせて更新してください。
